# ПрофВизор — бэкенд (фаза 2.1)

Бэкенд генеративного визуализатора забора: продавец загружает фото участка
клиента, указывает профиль/цвет/границы забора — сервис перерисовывает фото
через генеративную модель и возвращает фотореалистичный результат.

ТЗ: `~/Downloads/profvizor-backend-tz.md` (не в этом репозитории).

## Быстрый старт (без ключей — mock-провайдер)

```bash
python3.12 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env      # IMAGE_PROVIDER=mock по умолчанию
uvicorn app.main:app --reload --port 8420
```

Откройте http://localhost:8420 — загрузите фото, настройте параметры,
нажмите «Сгенерировать». Mock-провайдер рисует наложение сам (без внешних
API и денег) — это для проверки всего пути, а не финальное качество.

## Тесты

```bash
python -m pytest
```

## Переключение на реальный провайдер

В `.env`:

```
IMAGE_PROVIDER=gemini      # | flux-pro | flux-max | seedream
GEMINI_API_KEY=...         # только тот ключ, что нужен выбранному провайдеру
```

⚠️ Реализации `gemini` / `flux-pro` / `flux-max` / `seedream`
(`app/providers/`) написаны по документации без реального вызова — ключей
на момент разработки не было. Перед P0-сравнением провайдеров на реальных
фото (раздел 6 ТЗ) проверьте актуальные эндпоинты и формат ответа,
особенно для Seedream (slug модели на fal.ai — `FAL_SEEDREAM_MODEL` в `.env`).

## Промпт

Шаблон — `app/prompt_template.txt`, не зашит в код специально (раздел 6 ТЗ:
почти наверняка придётся донастраивать по результатам тестов).

## Приватность фото (раздел 9 ТЗ)

Фото и результат нигде не пишутся на диск — обрабатываются в памяти запроса
и возвращаются клиенту как `imageBase64` в ответе. Формального TTL-хранилища
нет, потому что хранить нечего — это строже требования ТЗ (≤24ч), а не слабее.

## Лимиты

`DAILY_LIMIT` / `MONTHLY_LIMIT` в `.env` — считаются по фактическим вызовам
провайдера (включая автоповтор при 502/504), не по HTTP-запросам, и хранятся
в SQLite (`data/profvizor.db`), переживают рестарт сервера.

## Пароль доступа

`SITE_PASSWORD` в `.env` — если задан, вся страница защищена HTTP Basic Auth
(общий пароль для менеджеров, открытый вопрос §12 ТЗ). Пусто — доступ открыт.

## Деплой

`Dockerfile` — `docker build -t profvizor . && docker run -p 8000:8000 --env-file .env profvizor`.
Секреты — только через переменные окружения, никогда в образ/код.
